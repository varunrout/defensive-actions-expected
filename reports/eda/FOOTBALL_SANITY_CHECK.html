Coverage gap

marking_tightness and is_goal_side_of_nearest_attacker are NOT independently checkable by this script. Both need the full list of visible attackers per frame, and this parquet only exports the top-3 ranked passing options, which aren't necessarily the same set as "all visible attackers" (an attacker can be visible without being one of the top-3 ranked pass targets). Recomputing them from what's actually exported would not be an independent check -- it would just re-derive the same already-stored inputs. This is an open gap, not a silent omission.
